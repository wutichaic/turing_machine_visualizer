    Transitions
    
            
    One transition per line. Read it as “in state, reading symbol → go to state, write, move”.
    

    q0, 0 -> q1, x, R     // write x, move right
q1, {0,y} -> q1, R    // set of symbols; omit write to keep the symbol
q2, * -> q2, L        // * reads any symbol
q3, # -> qa, S        // # is the blank; S means stay
q0, Z -> q0, Z, R     // Z is the left end of a one-way tape
    
            
    Diagram labels
    
            
    Edges are labelled read/write,move, for example 0/x,R. The written symbol is always shown, so q1, {0,y} -> q1, R is drawn as 0/0,R and y/y,R.
    
            
    Multi-tape
    
            
    Use brackets with one entry per tape for reads and moves. Tape 1 is the read-only input tape: its head moves only R or S, and its write is left out, so the write list covers tapes 2, 3, … only. * in a write keeps what was read. On a one-way tape every tape starts with Z in cell 0.
    

    tapes 2
init, [Z, Z] -> push, [Z], [R, R]
push, [a, #] -> push, [a], [R, R]    // writes a on tape 2
pop, [b, a] -> pop, [R, L]           // omit writes to keep symbols
    
            
    Diagram labels read (a,#)/a,(R,R): the symbols read on every tape, the symbols written on the work tapes, then the moves.
    
            
    Nondeterminism
    
            
    Give a state more than one transition on the same symbol. The simulator explores every branch and accepts if any branch accepts. Add mode deterministic to have overlaps reported as errors instead.
    
            
    Directives
    
            
    
              
    name "…"Title shown on the diagram
    
              
    start q0Start state (required)
    
              
    accept qa qbAccepting states
    
              
    reject qrRejecting states. A missing transition also rejects.
    
              
    tapes 2Number of tapes (inferred from brackets if omitted)
    
              
    blank #Blank symbol. Default is #; change it only if you need # as an ordinary symbol.
    
              
    input "0011"Default input, written on tape 1
    
              
    tape onewayDefault. One-way tape: cell 0 holds the left-end marker Z, the input starts in cell 1, and the machine starts with its head on Z. Z must be written back as Z, and moving L from Z rejects.
    
              
    tape infiniteTwo-way infinite tape with no end marker; the head starts on the first input symbol.
    
              
    mode nondeterministicor deterministic; inferred if omitted
    
              
    layout q0 0 120Pin a state's position. Drag states, then use “Save positions”.
